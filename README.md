# Cidade Verde ⚡

Um jogo simples onde o jogador joga um dado, e é afetado pelas casas onde cai, permitindo pequenas escolhas em seu caminho.

## 🚀 Tecnologias
- HTML
- CSS
- JavaScript

## 🎮 Funcionalidades
- Dice rolls;
- Escolhas;
- Efeitos de casas

## 🧠 Aprendizados
- Organização de CSS
- Lógica de estados
- UI/UX
- DOM
