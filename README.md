# Cidade Verde ⚡

Um jogo simples onde o jogador joga um dado, e é afetado pelas casas onde cai, permitindo pequenas escolhas em seu caminho.

## 🚀 Tecnologias
- HTML
- CSS
- JavaScript

## 🎮 Funcionalidades
- Dice rolls;
- Escolhas;
- Efeitos de casas

## ▶️ Como rodar

As páginas não funcionam ao abrir diretamente no navegador, é necessário rodar um servidor local.
Portanto, segue as instruções abaixo:

### Opção 1 — npm (recomendado)

```bash
npm install
npm run start
```

Acesse em: [http://localhost:3000](http://localhost:3000)
